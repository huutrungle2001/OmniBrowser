# OmniBrowser legacy archive

This private repository preserves the original OmniBrowser implementation and
its history. Active development has moved to the independent, minimal
[OmniBrowser v2](https://github.com/huutrungle2001/OmniBrowser-v2) project.

The final snapshot retains the previously uncommitted Vevox recipes and helper.
Generated caches, temporary files, and captured browser session/sitemap data are
not part of the source archive. Local copies were moved recoverably to Trash.

The authenticated Chrome profile is separate from this checkout and is not
included or changed by the migration.
